# MediaLink API

In mid 2017, we began work on a new API for MotorPress. It was designed and built for a single purpose:
Toyota South Africa wanted to use media published on MotorPress on a Toyota Branded news website.

Over the following 6 years, an additional 18 clients began using the API to publish content directly on
their websites. Around 60% of MotorPress usage comes through The API (renamed MediaLink).

## A New Version

Around 2024, we began talking about a brand new version of MediaLink. The original was never designed to
as a public-facing API and was always intended for use internally. In 2025, I started documenting what we've
dubbed MediaLink 2. The API is currently in development, and I've roped in an extra developer to help with
the workload.
