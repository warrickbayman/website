# Laravel Model Presenter

IsPresentable is a package designed to aid in associating presentation data with Laravel models. Since I work a lot on
both backend and frontend components, it made sense to be able to pass model attributes to the frontend without needing
to build more complex APIs. IsPresentable is one of the first open source packages I ever built, and it's still used in
a few places.

It's really simple, but does the trick.
