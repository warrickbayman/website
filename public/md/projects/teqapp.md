# Engineering Job Management

The original version of TeqApp was build by developers at Mycalture (a previous employee), although the
original name was simply DTeq Online. DTeq is a air-conditioning installation and maintenance company
based in Johannesburg, South Africa. Their clients include a number of large shopping malls, office
buildings and other commercial properties.

DTeq wanted a system that could help them manage their day-to-day jobs by automatically assigning job
numbers, associating air-conditioner units, technicians and team leaders while also managing time
frames.

Every single job that DTeq performs is now run through the TeqApp application. Each jon gets a unique
job reference number. Admins can then select a customer, select the individual units that need attention
and assign the job to a team or technicians.

Technicians can then manage their time on site by using a simple time tracking system. Jobs can be
started, paused and stopped when complete. The system is navigated through a browser but is primarily
used through mobile devices carried by technicians. This also allows the technicians to capture images,
collect signatures and comments on the go.

## Difficult Beginnings

I inherited the original source for the DTeq Online application while still employed with Mycalture.
The application code was a mess and and proved to be extremely difficult to manage. However, we were
able to complete the project after the original application was delayed by several months.

In 2023, the original application was replaced by a complete rewrite. Every feature from the DTeq Online
application was replicated and rewritten. We were able to work around long standing performance problems
and massive UX issues that had existed in the original application for a long time.

The current application now runs two separate profiles for DTeq and two new clients are set to start
with the application in 2026.
